# RoadForge (Forge 1.20.1)

Этап 2-3: меню с 3D-превью, выбор блоков, клавиша в настройках управления.

## Сборка jar на GitHub
Залей папку проекта в репозиторий. Workflow `.github/workflows/build.yml` соберёт jar
(Actions -> Build mod jar -> Artifacts -> roadforge-jar). Ничего из libs/ коммитить не нужно.
Для установки в игру нужны моды RouteMod 1.5.0 и (по желанию) Road Markings 1.1.0.

## Локальный запуск (по желанию)
JDK 17, jar-ы модов в `libs/`, Gradle 8.1.1, `genIntellijRuns`, `runClient`.

## Как пользоваться (права оператора)
- `/give @s roadforge:road_wand` - жезл. ПКМ - начало, ещё ПКМ - конец. Shift+ПКМ - построить.
- Клавиша **K** (меняется в Настройки -> Управление -> RoadForge) открывает меню:
  вкладка «Дорога» (тип, полосы, ширины, разметка), вкладка «Блоки» (выбор блоков из списка модов или обычных),
  справа 3D-превью из настоящих блоков (ЛКМ-тяни - вращать, колесо - масштаб).
  Кнопки: Построить / Отменить / Сброс точек.
- Настройки сохраняются в `config/roadforge-client.json`.
- Команды: `/road preset|lanes|info|build|undo|clear`, `/roadforge check|sample`.

## Профиль дороги
Полоса = 3 блока асфальта; между полосами колонка разметки; на краю сразу бордюр (тротуар).
