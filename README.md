# RoadForge (Forge 1.20.1)

Дороги, перекрёстки, парковки, меню с 3D-превью.

## Сборка jar на GitHub
Workflow `.github/workflows/build.yml` собирает jar (Actions -> Artifacts -> roadforge-jar).
Для игры нужны RouteMod 1.5.0 и (по желанию) Road Markings 1.1.0.

## Как пользоваться (права оператора)
- `/give @s roadforge:road_wand` - жезл. Клавиша **K** открывает меню (меняется в Управлении).
- Режим «Дорога»: ПКМ - начало, ПКМ - конец, Shift+ПКМ - построить.
- Режим «Перекрёсток» (вкладка «Перекрёсток»): ПКМ - центр, Shift+ПКМ - построить.
  Ветки С/В/Ю/З включаются кнопками: 4 ветки = крест, 3 = Т-образный, 2 соседние = поворот.
  Главная дорога строится по настройкам вкладки «Дорога», поперечная - по числу полос на вкладке «Перекрёсток».
  После постройки в чате будут координаты блоков, с которых продолжать дорогу за концом каждой ветки.
- Режим «Кольцо»: ПКМ - центр, Shift+ПКМ - построить. Радиус острова и полосы кольца - на вкладке «Перекрёсток»;
  на каждой ветке «уступи дорогу», зебра и островок-убежище, вокруг кольца площадка тротуара с фонарями.
- Угловые бордюры: из выбранного `routemod:trottoir_*` автоматически берутся `coin_exterieur_*` (выпуклый угол),
  `coin_interieur_trottoir` (вогнутый) и `trottoir_diago_*` (45°). Ориентацию подгоняй на вкладке «Повороты»
  (три строки «Бордюр: ...»), превью справа сразу показывает результат.
- Деревья: вкладка «Дорога», «Деревья, шаг» - по центру газона (разделитель, обочина) и на острове кольца. Листва не опадает.
- Режим «Изгиб»: ПКМ - точка A, ПКМ - точка B, Shift+ПКМ - построить. Дорога идёт от A прямо, поворачивает на 90° дугой
  и приходит в B. Кнопка «От A: вдоль X/Z» выбирает, по какой оси идёт первый участок; участки не короче радиуса дуги.
- Переходы на обычной дороге: вкладка «Дорога», «Переход каждые N» (0 = без переходов).
- Вкладка «Парковка»: параллельная / под углом / перпендикулярная, справа и/или слева.
- Вкладка «Повороты»: если зебра, бордюр, фонарь, уклон или диагональная линия повёрнуты не туда,
  подкрути угол: превью покажет результат сразу.
- Настройки сохраняются в `config/roadforge-client.json`.
- Команды: `/road preset|lanes|info|build|undo|clear`, `/roadforge check|sample`.

## Профиль
Полоса = 3 блока асфальта; между полосами колонка разметки; у проезжей части ровно один блок бордюра
(роль «Бордюр»), дальше покрытие тротуара (роль «Тротуар», по умолчанию обычные блоки). Под всей постройкой -
подложка из чёрного бетона (`Foundation`: минимум 2 слоя, вниз до земли).
Двойная осевая: линия, зазор, линия. Рекомендуемый масштаб интерфейса: 3 или меньше.
